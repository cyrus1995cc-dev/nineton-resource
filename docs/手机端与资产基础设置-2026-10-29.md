# 手机端与资产基础设置

手机工作台采用功能宫格和五项底部导航：工作台、资产、扫一扫、审批、我的。桌面端保留侧栏和资产表格。手机新增、编辑和人员选择采用全屏表单，底部保存按钮保留安全区。

## 新增资产

资产管理员和超级管理员在“资产清单 → 新增资产”或手机工作台的“新增资产”入库。普通员工不显示新增和配置入口，接口也检查权限。

选择分类后自动加载绑定卡片，并预览编码。编码只能自动生成：分类中的字母编码为前缀，后接短横线与流水号。编号按相同前缀的现有最大数字后缀续号，保存时在数据库事务中锁定分配；预览不占号。失败回滚，重复请求幂等返回，多个账号并发新增不会分配相同编号。已贴的旧编码和二维码不重写。

公司选择来自系统公司资料。使用人按通讯录员工 ID 选择，自动带出姓名和部门，可搜索姓名、部门或工号；同名员工仍使用各自身份。无使用人时为空闲，有使用人时为在用。目录未同步时允许空闲入库，不能通过手输姓名建立人员身份。

首次登记可填写使用人、位置和领用日期。已有资产的归属变更仍通过流转审批，编辑资料不会绕过此限制。

## 分类、编码与卡片

超级管理员可在桌面“分类与卡片”或手机“我的”的管理入口配置：

- 资产分类：一级、二级分类，名称、编码、状态、备注和卡片绑定。分类改名同步台账分类，修改前缀只影响之后新增。
- 编码规则：流水号最少位数、下一号。系统核对已有编码，禁止回退至已分配编号。
- 资产卡片：默认通用、电脑、办公设备、办公家具、办公电器五种，可新增模板，配置标准字段、自定义文本、数字、日期和选项及必填规则。

以上变更有版本检查，避免覆盖其他管理员的修改。停用被启用分类引用的卡片、停用仍有启用子分类的父分类会被拒绝。

## 数据与接入

使用新增的目录、规则、资料扩展、幂等请求表保存元数据，现有台账字段、旧二维码和历史资料保留。升级先备份数据库与环境配置、运行迁移工具建表，再切换程序。首次启动根据既有资产分类初始化目录。

真实通讯录同步需要服务端配置 CorpId、Client ID、Client Secret 及钉钉应用的通讯录授权范围。AgentId 不代替 CorpId。配置均保存在私有环境文件，不提交仓库。统一登录凭据不能代替通讯录应用凭据。审批消息真实发送仍需单独联调。

## 验证

Go 集成测试覆盖自动续号、失败回滚、重复提交、跨账号并发、防手工编码、员工身份、权限、卡片字段校验、分类改名和版本冲突。前端执行类型检查、现有单元测试；独立测试库浏览器验证新增、编辑、同名员工选择及基础设置，检查手机和桌面尺寸。浏览器模拟不代表钉钉真机或原生 APK 验收。
