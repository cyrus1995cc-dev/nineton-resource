# 九吨资产品牌与界面

系统名称统一为「九吨资产」。使用用户提供的透明 PNG 作为品牌图标，原图保存在 `frontend/public/brand/jiudun-mascot.png`，登录页和侧栏通过 `BrandLogo.vue` 复用；浏览器图标、Apple 添加到主屏幕图标和 Web App manifest 也引用同一资源。Android 工程的应用名称同步更新，未重新生成 APK。

配色以图标中的深蓝、青色和橙色为基础：深蓝侧栏、青色主要操作、橙色辅助提示，登录页新增品牌展示区。看板、清单、表单、组织管理和流转页面使用共享品牌变量。样式入口为 `frontend/src/brand.css`，在原有基础及业务样式之后加载；统计图颜色也使用同一变量。

保留资产清单的固定列、独立滚动、密度和列偏好、筛选、批量操作和分页行为。手机继续显示资产卡片，登录页切换为上下布局，导航可横向滚动。资产详情页的使用部门也复用清单的一级部门展示规则。移除登录页公开展示的开发默认密码，账号及登录流程沿用原实现。

验证包括前端 23 项测试、Vue/TypeScript 类型检查与生产构建，以及 320px、390px、844px、1366px、1600px 的浏览器显示检查。桌面清单分页位于视口内，页面无横向溢出；登录、筛选搜索、资产详情和品牌图片加载通过检查。

生产发布只替换新的前端静态文件，复用现有 Go 程序，不涉及业务数据库迁移、账号变更或证书更换。发布到独立 release 目录并核对 SHA256 后原子切换 `current` 软链接，保留前一版本供回退。
