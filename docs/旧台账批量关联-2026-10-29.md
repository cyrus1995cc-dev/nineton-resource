# 旧台账批量关联

入口：组织与人员 → 旧台账关联。

旧台账按“原使用人 + 原部门 + 原公司”合并分组，同组资产可以一次关联。公司、部门、使用人文字及资产状态保持原记录，只补上系统员工身份。

## 操作步骤

1. 点击“唯一同名候选”，或搜索指定使用人、部门、资产编码。
2. 点击“选择筛选内唯一匹配”，选择当前筛选结果所有分页的分组；也可逐组勾选。
3. 核对钉钉员工的部门、工号及原台账信息。唯一同名候选只是预填，不代表自动确认身份。
4. 点击“批量关联已选”，在确认页再次核对人员、资产件数及编码明细。
5. 点击“确认关联 N 件资产”。重名人员必须先手动选择对应员工，也可用“关联该组 N 件”。

搜索或筛选后再点击“选择筛选内唯一匹配”，会以当前筛选结果替换原选择。每次最多处理 2000 件资产。

## 离职和停用人员

按管理员确认的业务口径，当前同步通讯录没有同名人员的旧台账列入“离职人员资产”，不参与在职员工批量关联。原使用人、公司、部门和资产状态保留，管理员后续通过回收或交接流程处理。

当前通讯录中仍存在、但系统已停用的人员单独列为“员工已停用”。

## 冲突及记录

只有超级管理员可以执行关联。服务端逐件检查资产版本、原姓名、有效员工、已有绑定和待审批单据。任一件冲突时整批撤回，不会只完成部分关联。

冲突后取消确认框，点击“刷新待关联”重新核对。请求结果未知时可重试，已关联到同一员工的资产会跳过，不重复写入关联事件和审计。

每件成功关联的资产都记录关联原因、操作人及员工身份。关联完成后，普通员工按员工身份查看本人资产。

本次更新不自动提交生产台账关联，也不修改离职人员资产状态。
