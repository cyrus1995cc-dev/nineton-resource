# 员工资产范围与手机布局修复

## 资产访问规则

- 普通员工和审批人的资产清单、状态统计、筛选选项、Excel 导出、编码查询和扫码详情，统一按 `assignee_employee_id = 当前员工 ID` 限制。
- `scope=available`、指定编码及筛选参数均不能扩大员工范围。空闲库存及他人资产不可见。
- 待审批单据保留相关申请人、接收人、指定审批人的查看权限；单据快照不再赋予台账访问权限。
- 员工可申请本人资产的归还、交接、维修、报失。新资产领用联系管理员分配，不再提供库存浏览入口。
- 超级管理员和资产管理员保留管理范围。新建系统账号的界面默认角色为普通员工。
- 未关联员工身份时显示关联提示，不按姓名或邮箱自动认领。

## 存量资料需要核对

截至本轮发布前，生产有 1,762 件资产，其中 1,249 件填写了使用人姓名，但尚未关联钉钉员工 ID。本轮不自动修改其归属。

1. 管理员在“组织与人员 → 旧台账关联”核对姓名、部门与工号，再关联真实员工。
2. 经统一登录进入的新账号尚未关联员工时，在“账号权限 → 关联已有账号”核实统一登录身份编号，将其绑定到对应钉钉员工账号。原超级管理员的身份绑定保留。
3. 关联完成并重新登录后，员工即可查看本人的已关联资产。同名人员不会自动合并。

## 手机布局

- 手机资产状态标签改为数量和状态选择框，解决窄屏时标签收缩、文字与数量叠加及横向滚动问题。
- 通讯录标签改为两列布局，完整显示四个管理入口。
- 统一窄屏及手机横屏断点，修复横屏时表单、组织树、审批详情残留的桌面布局。
- 长编码、型号、公司、员工及部门名称换行；操作按钮可换行；输入项和选择器限制在容器内。
- 资产清单使用正常文档滚动，固定底栏保留内容空间，表单保留可滚动区域和安全区。

## 钉钉入口提醒的核查结果

用户确认提醒在点击工作台“九吨资产”后立即出现。后台截图中的移动端首页、PC 首页、管理后台均为 `https://xz.vodayapp.com/`，填写正确。

服务器检查：HTTPS 首页返回 200，没有 Location 跳转；HTTP 仅 301 到相同域名的 HTTPS 首页。本轮没有改动钉钉后台，没有宣称安全提示已解除。

需在钉钉后台继续核对当前发布版本与安全设置中实际提供的域名配置项。若配置正确且正式工作台入口仍出现提醒，使用提醒页“反馈误报”或钉钉官方支持核查该 URL。配置可信域名是否能消除该提示尚未证实，不能视作已解决。

钉钉[官方 H5 常见问题](https://open.dingtalk.com/document/development/h5-micro-application)说明了应用首页域名及跨站跳转可能影响免登授权；该说明并不证明本次安全提醒由统一登录或某一域名配置导致。
