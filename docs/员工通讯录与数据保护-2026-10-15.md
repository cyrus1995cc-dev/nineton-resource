# 员工通讯录与数据保护

日期：2026-10-15。按本轮授权先完成数据完整性、通讯录与员工权限基础。

## 使用入口

- 管理员登录后进入“系统设置 → 员工与部门”。员工列表支持姓名、部门、工号搜索及每页 20 项分页。
- “同步设置与记录”设置授权起始部门编号、手动或定时同步；默认关闭定时同步。可选择 30 分钟、1 小时、6 小时、每天。
- “旧台账关联”核对台账姓名与钉钉员工，结合部门与工号选择，填写关联原因后保存。没有默认自动选择；重名须人工确认。此操作只补充身份关联，换人须走交接审批。
- 账号管理支持创建、角色调整、启用和停用。角色或状态调整撤销旧会话；不能停用本人或将仍有待处理审批的人降权/停用。
- 员工登录后使用“我的资产”、可领用库存和“我的待办”；领用对象固定为本人，部门由身份记录确定。

## 钉钉配置条件

后端启动环境需要以下参数，不在前端或本文件保存密钥：

```powershell
$env:DINGTALK_CLIENT_ID="企业应用AppKey"
$env:DINGTALK_CLIENT_SECRET="企业应用AppSecret"
$env:DINGTALK_CORP_ID="企业CorpId"
```

配置后重启后端。在钉钉后台申请企业内部应用的通讯录部门信息和部门成员读权限，并设置授权范围。全企业范围的根部门编号通常为 `1`；部分授权填写实际可访问部门编号，多个用逗号分隔。

同步读取部门树及各部门分页成员，按企业 corpId + userId 保存稳定员工身份，unionId 另存用于核对登录身份。整个远程读取成功后一次事务写入；接口失败保留现有通讯录。新增员工自动建立普通员工账号，不设置可本地登录的密码；现有角色和管理员停用状态不被同步覆盖。

未再读到的员工标为“授权范围待核对”，暂停关联账号访问及会话；不自动认定离职或删除，历史和名下资产保留。恢复授权范围并重新同步后可解除待核对标记，人工停用状态仍保留。停用前有待审批单据时先处理单据，审批转交功能尚未实现。

官方接口参考：[获取企业应用令牌](https://open.dingtalk.com/document/development/obtain-orgapp-token)、[部门列表](https://open.dingtalk.com/document/development/user-management-acquires-the-list-departments)、[部门详情](https://open.dingtalk.com/document/development/query-department-details0-v2)、[部门成员详情](https://open.dingtalk.com/document/development/queries-the-complete-information-of-a-department-user)。令牌使用新版 `/v1.0/oauth2/accessToken`，部门与成员使用对应的 v2 接口。

## 权限范围

| 角色 | 当前范围 |
| --- | --- |
| 管理员 | 全公司台账、资料、导入、盘点、申请、审批、系统及人员设置 |
| 资产管理员 | 全公司台账、资料、导入、盘点、申请及分配的审批 |
| 只读用户 | 全公司台账、单据与履历只读 |
| 普通员工 | 本人员工 ID 关联的资产、可领用空闲库存、本人申请/接收/参与审批的单据 |
| 审批人 | 员工能力及分配给自己的审批步骤，待审批涉及资产可查看 |

普通员工可发起领用、归还、交接、报修、报失，不能导入或直接改台账。领用只能本人；其他申请必须为本人名下资产；指定审批仍逐级进行且不能自审。最终审批重新检查资产快照和接收员工有效性。

管理角色的公司/部门范围尚未细分。员工姓名相同不会自动取得他人资产；历史台账要先核对关联到稳定员工 ID。

## 数据保护

1. **导入：** 预览由服务端保存原始数据、操作者及台账版本，30 分钟过期。确认只使用批次 ID，拒绝他人确认、过期或预览后数据变化；重复确认返回原结果。已有资产的状态、使用人、部门、位置、领用日期不允许通过导入直接变更，相关整行跳过。新资产首次迁移允许填写初始归属。
2. **履历：** 普通资料导入逐项记录真实操作者、字段前后值、来源文件和批次；人员关联及账号状态变更留审计，资产姓名不因身份关联被静默改写。
3. **编辑：** 保存时检查资产版本号，冲突提示重新核对，页面只提交实际修改的资料字段。
4. **校验：** 名称、金额、日期、状态、编码、长度和分页在后端检查。编码导入与二维码解析使用同一规则。
5. **二维码：** 已有非空原文固定保存；同资产的其他扫码内容存为别名，扫码不打开供应商网址。
