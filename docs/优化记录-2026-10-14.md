## 本地使用

电脑在项目目录执行 `npm run dev` 后，访问 `http://localhost:5173`。

更新的 Android 测试安装包位于 `android/app/build/outputs/apk/debug/app-debug.apk`，使用 `http://192.168.21.130:3000` 连接电脑。电脑需启动后端，手机和电脑在同一局域网。电脑 IP 改变后需要重新打包。
