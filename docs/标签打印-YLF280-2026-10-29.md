# YLF-280 资产标签打印

默认打印机为 Windows 已安装的 YLF-280 Label Printer（DT-280 驱动），纸张为 E 50 × 30 mm。

## 使用

1. 进入“资产清单”，勾选资产，点击批量操作栏中的“打印标签”。支持跨页选择，最多100件。
2. 选择标签样式和每件张数，核对总张数及标签预览。每件1至20张，每批最多1000张。
3. 点击“打开打印预览”，在浏览器中选择 YLF-280 Label Printer，纸张 E 50 × 30 mm，缩放100%（实际大小），边距无，关闭页眉页脚。浏览器份数保持1，避免再次倍增。
4. 检查预览为宽50mm、高30mm；现有驱动包含“右转90°”选项，如方向不正确，应核对驱动旋转与浏览器布局，避免重复旋转。
5. 第一次先选一件试打，确认实物位置和扫码效果，再批量打印。可用左右、上下偏移（-3至3mm）微调，偏移仅存于当前浏览器。

单件入口：“资产详情 → 更多 → 打印标签”。

## 标签样式

超级管理员通过侧栏“基础设置 → 标签样式”，或手机“我的 → 标签样式”，新增、修改、复制、删除模板，最多保存20个，至少保留一个。资产管理员可使用样式打印，普通员工不能访问批量标签数据。

默认样式为左侧二维码、右侧名称和编码。支持毫米尺寸、二维码大小、边距、字号和可选标题。名称、编码必选，可再加入公司、型号、位置或使用部门，最多4个字段。

编码完整显示，其他长文本最多两行，超出显示省略号。系统在打印前检查实际排版，文字、二维码或其留白超出纸张时会阻止打印，需减小字号、减少字段、放大标签或调整偏移。

## 二维码和登录

新标签使用 `https://xz.vodayapp.com/a/资产编码`，无论在本地预览还是线上打印，默认均指向正式域名。其他部署可在构建前设置 `VITE_PUBLIC_APP_URL`。二维码在浏览器内生成，不向外部二维码服务传送资产信息。

扫码打开九吨资产后，维护账号、钉钉或统一登录成功会回到该资产，原有查看权限继续生效。普通员工仍只能查看本人资产。旧公贝二维码原文和别名不会被打印操作覆盖，已有旧标签仍可在系统内扫描识别。

## 运行与验证

前端编译后静态部署，服务端仍为 Go。模板使用现有 system_settings 存储，不新增数据库表；保存、删除有审计和版本冲突检查。打印只读取当前资产，不修改业务台账，不伪造“已经打印成功”记录。

浏览器通过已安装的 Windows 驱动调起打印对话框。网页无法静默指定 USB 打印机或确认实际出纸；首次实机试打仍需核对。

本次验证包含前后端测试、模板增改删与权限、单件和批量预览、长文本、偏移越界、二维码解码、登录直达、320/390/430/844触屏和1440桌面布局，以及50×30mm输出分页。测试未发送实体打印任务。
