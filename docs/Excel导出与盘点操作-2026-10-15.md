# Excel 导出与盘点操作

日期：2026-10-15。按“先做导出，再看看盘点怎么做”完成本轮功能。

## 一、导出入口

| 页面 | 操作 | Excel 内容与范围 |
| --- | --- | --- |
| 资产清单、我的资产 | 设置搜索、状态、位置后点“导出 Excel” | 全部符合筛选且有权查看的资产，忽略分页；资产清单、导出说明两张表 |
| 资产流转 | 选择全部记录、我的待办或我发起的，设置搜索和审批状态后导出 | 流转单据、流转资产明细、审批步骤、处理记录、导出说明五张表；不包含评论 |
| 资产盘点 | 打开某个任务，点“导出盘点结果” | 任务概况、全部明细、差异清单、导出说明四张表；不受页面明细搜索、结果筛选或分页影响 |

导出与列表使用相同权限条件。普通员工、审批人只能导出其可见资产及相关单据，不能通过修改范围参数查看其他人的数据；管理员、资产管理员、只读用户当前仍为全公司范围。盘点只对这三类管理/只读角色开放，只有管理员和资产管理员可创建、登记和结束任务。

资产表保留原导入兼容的 22 列，另加“二维码原文”。金额是数值单元格，序列号和二维码是文本；前导零、长序列号及以等号开头的备注不转换为数值或公式。原始创建时间、领用日期按台账文本保留；系统操作时间和导出时间明确为北京时间。

流转资产明细使用提交时快照，盘点明细使用任务创建时快照，后续台账变化不回写这些历史数据。导出不会改变资产、审批或盘点结果。服务端成功生成后保存导出审计，含导出人、时间、筛选和记录数；这条审计不表示接收设备已经保存文件。

### 下载和限制

- 网页：浏览器下载 Excel，可在下载列表打开。
- 安卓 App：覆盖安装新版 APK 后导出，系统弹出保存窗口，选择文件夹并保存；取消会提示已取消。无需额外申请整个存储目录访问权限。
- 每张工作表最多 50,000 条业务记录；任意明细表超限会整体报错，避免得到不完整文件。资产和流转可缩小筛选范围，盘点建议按楼层拆分任务。
- 安卓单文件上限 16 MB，超过请缩小范围或使用电脑网页。
- 登录过期、无权限、连接失败、保存失败会明确提示。旧 APK 缺少保存能力时会提示更新或改用电脑版。

## 二、建议先按一个楼层试盘

例如先做“12楼季度盘点”，操作如下：

1. **建任务。** 管理员或资产管理员打开“资产盘点”，填写名称、选择“12楼”，点击创建。系统保存创建时该范围的应盘资产清单及其状态、使用人、部门、位置快照。后新增的资产不会自动进入既有任务。
2. **现场扫描。** 手机连接系统，打开同一任务，填写现场实际楼层，使用安卓 App 扫描原有标签二维码，也可手工输入编码。系统只解析二维码内容，不打开供应商网址。实盘位置会沿用上一次填写的值，换楼层时要及时修改；留空按该项任务快照中的位置登记。
3. **核对结果。** 进度展示应盘、实际已盘、待盘、差异。位置与快照相同为“正常”，不同为“位置差异”。重复扫描相同位置和备注不会重复计数、重复写履历；更改位置或备注会更新登记并留履历。
4. **复查后结束。** 搜索待盘及位置差异，确认无误后点“结束盘点”。确认窗口会提示剩余待盘数量；结束后剩余项转为“未盘到”，任务不可继续登记。误结束后目前需要重新建任务复盘。
5. **导出并处理。** 下载整个任务结果，逐项核实差异。需改变位置、部门、使用人时提交调拨或交接审批；确有丢失时另走报失审批。盘点本身不直接修改台账归属或位置。

### 计数规则

| 结果 | 计入实际已盘 | 计入差异 | 含义 |
| --- | --- | --- | --- |
| 待盘 | 否 | 否 | 任务进行中，尚未登记 |
| 正常 | 是 | 否 | 已登记且实盘位置与任务快照相同 |
| 位置差异 | 是 | 是 | 已登记但实盘位置不同，需核实 |
| 未盘到 | 否 | 是 | 结束时仍未登记，不等于已经丢失 |

扫描范围外资产会提示“资产不在本次盘点范围内”，不会自动扩展本任务。先查询它的台账位置，记下现场信息，再选择它所在范围的任务核实；台账位置为空的资产也要另外检查，单楼层任务不会覆盖它们。

## 三、当前盘点边界和后续建议

目前为在线盘点，手机需持续访问电脑上的服务。没有离线扫码后同步、盘点任务分配、照片附件、范围外资产登记表或差异处理关闭流程；钉钉推送也尚未企业联调。

建议先完成一个楼层的实际扫码和差异复核，再根据现场反馈优先考虑：

1. 范围外资产登记与差异处理状态，让“发现问题 → 核实 → 发起审批 → 处理完成”可追踪。
2. 按楼层或人员分配任务；接通钉钉后再推送盘点待办、催办和结果。
3. 现场网络确实不稳定时，再补离线任务下载、扫码队列和同步冲突处理。

上述为后续建议，本轮没有增加这些功能。
